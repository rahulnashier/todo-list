# todo-list
A simple to-do list app built with plain HTML, CSS and JavaScript.

🔗 Live site: https://rahulnashier.github.io/todo-list/

## Features
- Add new tasks
- Mark tasks as complete
- Delete tasks
- Tasks are saved automatically in the browser (localStorage)
- Edit task text
- Clear completed tasks
- Filter tasks by All, Active or Completed
- Mark all tasks as complete or active with one click

## Tech used

- HTML5
- CSS3
- Vanilla JavaScript
